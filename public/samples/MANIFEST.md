# public/samples — the Studio's "Try a sample" files

Real buildings' files found on the internet, each free to pass on, opened by the Studio's **Try a sample ▾** (the empty
Studio, under the dashed box) exactly as if they had been dropped. One of each kind Plotline reads: IFC, DXF, PDF, SVG and
a 3D model. Each file is the original download, unchanged, under a shorter name (the original name is in the source
column). Licences were read on each source page on the date checked. The list in the Studio is `src/studio/samples.ts`;
`src/studio/samples.test.ts` keeps it, this folder and this table equal.

These eight were chosen from the 53 files of `Docs/SAMPLES.md` (the whole tested set, kept on the office PC in
`E:/dev/ALTERNATIVE FORMAT TEST/samples-2026-11-22/`): the smallest ones whose licence lets anyone pass them on, at most
3 MB, at least one of each kind, preferring the ones that open well.

CC BY asks for the credit: it is here, in `Docs/SAMPLES.md`, and on each sample in the Studio's list (rest the mouse on
it). The SVG is CC BY-SA: passed on unchanged, with its licence; a changed copy of that drawing would have to stay CC
BY-SA.
