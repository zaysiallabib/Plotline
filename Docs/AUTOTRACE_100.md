# Auto-trace on 100 real sheets — what works, what needs work (session 25, 2026-10-14)

**What this is.** The founder's order of 2026-10-14: find 100 real apartment floor-plan sheets (Bangladesh first), test each one
the way he does (drop the sheet in the Studio, S on a printed size, Auto-trace → Whole floor), write down what came out, note every
room name the system does not know, add those as general segments, then list — and only then fix, one by one on a branch — the
things that need code. This file is that list. §1 where the sheets came from, §2 the scoreboard (one row per sheet), §3 the ranked
improvements, §4 the new segments (done today), §5 what was fixed today and how to check it.

**Method — the founder's path, nothing else.** Firefox (Playwright's build on E:), the real Studio at `/studio` on main `1d5eeb8`,
a fresh Studio per sheet, the sheet picture dropped on it, **S** clicked on the two wall faces of one room whose size is printed
(from a size table when the rooms carry none), the size typed, **Auto-trace → Whole floor** (plus one click per flat on
multi-flat sheets). Counts were read off the page text, the Check these rows and the screenshots with the review marks dismissed.
Shots + page texts: `E:/dev/plotline-shots/s25/<key>-floor.{png,txt}`, `-check.txt`, `-names.png`, `-q{nw,ne,sw,se}.png`.
Harness: `E:/dev/tmp/s25/run.mjs` (generic: a JSON of sheets → scale clicks → Whole floor / flat clicks; `probe.mjs` for pixel
crops, `dims.mjs` for sizes, `pdf/pdf2png.mjs` for brochure PDFs). Per-batch reports with every printed name, every result and
the sheet JSONs: `E:/dev/tmp/s25/batch{A..I}.md` / `.json`. Scored by agents acting as the founder; no JSON / node-only runs.

## 1. Where the sheets came from

`Demo drawings/<Developer> <Project>/` — 114 project folders, each with a `SOURCES.md` (page URL, file URL, developer, project,
date 2026-10-14, what each file shows). 314 image files + 45 brochure PDFs were collected (flat, whole-floor and level sheets; PDFs
rendered to PNG at 2×–4×, plan pages copied to the folder root); 110 were scored (§2). All Bangladesh: Dhaka (bti, Rangs,
Sheltech, Assure, Eastern Housing, Ena, Mir, Akter, Moonstone, Assort, Dominant, UPL, Accept, Arkam, Foysal, Nessa, Renown,
Crystal) and Chattogram (CPDL, Finlay, Prime Asset). Sources: the developers' own sites and brochure PDFs, and Bikroy developer
ads (those carry a "POSTED ON BIKROY" watermark). Not collected: sites behind a bot wall (JCX, Anwar Landmark, Amin Mohammad,
Starpath, Credence, Tropical Homes), render-only sites (Navana, Shanta, Suvastu, Doreen, Rancon), bdhousing (thumbnails only),
RAJUK / NHA (nothing public). Not scored (still in the folders): the ground / basement / rooftop sheets, Akter and Prime Asset
brochures, Moonstone, Crystal, Ena Sufias Serenade, Sheltech Windflower towers 2–4, most Palm Spring types.

Styles in the set: clean brochure graphics with grey floor tints and furniture (bti, Rangs, Finlay Chayaneer / Nirvana), raw CAD
plots with title blocks (Sheltech Windflower, Nessa, Arkam, Accept, Mir Ar Rahma / Jahan e Nur), grey walls with red columns
(Finlay Dilruba / Jahan Ara), coloured fills (Assure, Ena, UPL, Eastern Housing), scanned brochures (Mir Bhuiyan Manor / Premiere),
white lines on a dark page (bti La Montana), rotated text (bti The Peak, Finlay Palm Spring, Mir Premiere / Sarwar, Assort),
sizes in a side table instead of in the rooms (Rangs, CPDL, Ena legends), numbered rooms with a legend (Ena Jahan Lodge /
Karims Castle / Lake Resort / Miazi / Rose Garden). Flats from 890 sft to 5100 sft; whole floors with 2–7 flats.

## 2. The scoreboard

Columns: printed rooms = every named space of the flat on the sheet; closed + named = a closed room carrying a real name (wrong
names in brackets); Space N = closed but unnamed; open / missing = no closed room there. "Whole floor" numbers unless a flat
click is named. The full rows (with the lists of printed names and of what came out) are in the batch reports; this table is the
one-line version per sheet. Batches: A–B bti (21), C–D Rangs (21), E Sheltech + Assure (14), F CPDL (14), G Finlay (12),
H Ena + small developers (14), I Eastern Housing + Mir (14).
